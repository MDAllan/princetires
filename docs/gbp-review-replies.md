## How to apply these
- **Manual:** in your Google Business dashboard (or Metricool's review inbox if your plan has it), open each review and paste the matching reply.
- **Automated (true hands-off):** a GBP API script can pull all reviews and post replies automatically. Requires the one-time Google API access + OAuth (same setup as auto-posting).

## Cautions
- Replying to hundreds of old reviews in one burst shows a stack of replies all dated today — fine, but a bit obvious. Prioritize the most recent ~50 and anything negative, then keep up going forward.
- Match the reply to what the review actually says. A keyword-stuffed or mismatched reply reads worse than a simple "Thanks for the five stars."
