## 2. The Hands-Off Path (do this first — covers ~50 citations from one setup)

Pick ONE done-for-you citation service and feed it the data above. This is the single highest leverage-per-effort move:

| Service | What it does | Effort | Cost (approx) |
|---|---|---|---|
| **BrightLocal Citation Builder** (recommended) | Humans build ~50 Canadian + niche citations FOR you from one order; no recurring lock-in | Fill 1 form, then done | ~$2–4/citation, one-time |
| **Yext** | Auto-syncs NAP to 50+ networks (Apple, Bing, Yelp, Foursquare…) | 1 setup | ~$199+/yr (recurring) |
| **Moz Local** | Auto-distributes to major aggregators (Foursquare, Data Axle, etc.) | 1 setup | ~$129+/yr |
| **Uberall / Whitespark** | Similar managed citation distribution | 1 setup | varies |

> Recommendation: **BrightLocal Citation Builder** — one-time cost, you keep the links if you cancel, and it targets `.ca` directories. Yext is fine but you lose listings if you stop paying.

- **"Calgary winter tire changeover dates" guide** (data-backed, updated yearly) — local press cites these.
- **Tire size → price guide** — the kind of page carfromjapan.com / automobile101.com link to.
