## How to use this file

- Add a promo under the right brand (or **Store-wide** for shop offers).
- Always include **start + end dates**. Expired promos move to the bottom archive — don't delete them, they're useful history.
- One-liner format: `**Promo name** — what the customer gets. Valid <start> – <end>. <conditions>.`
- If a brand has no promo, leave it as `_None active._` so we know it was checked, not skipped.
